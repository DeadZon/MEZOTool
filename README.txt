DeadZone Logo Package
Developer: MEZO

Recommended paths inside the project:
assets/icons/deadzone_logo.png
assets/icons/deadzone_logo.ico

Files:
- deadzone_logo.png: main transparent PNG logo for the app UI.
- deadzone_logo.ico: Windows executable/window icon, black-background version for better small-size visibility.
- deadzone_logo_transparent.ico: transparent icon alternative.
- deadzone_logo_black_bg.png: dashboard/splash/about image with black background.
- deadzone_logo_1024.png, 512, 256, 128, 64, 48, 32, 16: transparent PNG sizes.
- deadzone_logo_black_bg_*.png: black-background PNG sizes.
- deadzone_logo_source.jpg: original uploaded source image.

Suggested PyInstaller flags on Windows:
--icon assets/icons/deadzone_logo.ico --add-data "assets;assets"

Window title: DeadZone Flash Tool
